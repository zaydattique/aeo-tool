# SEO, AEO, and GEO Launch Foundation

## Purpose

This is the launch-readiness checklist for the public Threezero AEO website.

It does **not** promise rankings. Search engines and AI systems independently decide crawling, indexing, ranking, citations, and answer inclusion. The purpose of this checklist is to ensure that the site launches with no known preventable discovery or technical foundation problems.

## Search foundation

### Crawl and index

- [ ] canonical production domain confirmed
- [ ] HTTPS enforced
- [ ] HTTP/HTTPS and host variants resolve correctly
- [ ] redirect map tested
- [ ] no redirect chains
- [ ] no redirect loops
- [ ] robots.txt reviewed
- [ ] intended crawlers allowed
- [ ] unintended private areas blocked
- [ ] no accidental noindex
- [ ] XML sitemap generated
- [ ] sitemap contains only intended canonical URLs
- [ ] sitemap has no 3xx/4xx/5xx URLs
- [ ] sitemap has no staging URLs
- [ ] sitemap lastmod values are truthful where used
- [ ] important pages are internally linked
- [ ] orphan-page report reviewed
- [ ] 404/410 behavior reviewed
- [ ] soft-404 risk reviewed

### Page architecture

- [ ] unique title for every important page
- [ ] useful meta description for every important page
- [ ] one clear primary heading
- [ ] logical heading hierarchy
- [ ] clean URL structure
- [ ] canonical URL on every indexable page
- [ ] Open Graph metadata
- [ ] social image metadata
- [ ] favicon/site identity
- [ ] language metadata
- [ ] hreflang only where actually justified
- [ ] crawlable HTML contains important content
- [ ] JavaScript does not hide critical content from crawlers

### Structured data

- [ ] Organization/entity markup where appropriate
- [ ] WebSite markup where appropriate
- [ ] SoftwareApplication/Product markup where appropriate
- [ ] BreadcrumbList where appropriate
- [ ] Article markup for editorial content where appropriate
- [ ] FAQ markup only where supported and genuinely applicable
- [ ] visible content matches structured data
- [ ] no fabricated structured-data claims
- [ ] validation completed
- [ ] representative URLs inspected after deployment

## AEO foundation

### Entity clarity

- [ ] Threezero AEO identity is consistent
- [ ] company/organization identity is consistent
- [ ] product category is explicit
- [ ] product purpose is explicit
- [ ] company relationship to threezero.agency is consistent
- [ ] About page is authoritative
- [ ] contact/company information is consistent
- [ ] terminology is consistent across pages
- [ ] no contradictory pricing or product claims

### Answerability

Important pages should make it easy for a human or retrieval system to answer:

- What is Threezero AEO?
- Who is it for?
- What does it measure?
- Which AI/search surfaces does it monitor?
- What are citations?
- What is AI visibility?
- How does the scoring methodology work?
- How does the product compare competitors?
- What technical SEO/AEO/GEO problems can it detect?
- How does the Action Center work?
- How are results rechecked?
- How are reports produced?
- What does the product cost?
- Who operates the company?
- How can someone contact the company?
- What are the product's security and privacy practices?

Each answer must be supported by substantive page content, not hidden text or keyword stuffing.

## GEO foundation

Where geographic relevance is legitimate:

- [ ] company location/market information is accurate
- [ ] contact details are consistent
- [ ] legitimate local/regional information is structured
- [ ] localized content has unique user value
- [ ] no mass-produced city doorway pages
- [ ] external business profiles are consistent
- [ ] language and locale signals are correct

## AI crawler and machine readability

- [ ] legitimate AI/search crawlers are intentionally handled
- [ ] important public content is crawlable
- [ ] no accidental AI crawler blocks
- [ ] llms.txt, if used, is treated as supplemental rather than a ranking mechanism
- [ ] machine-readable content agrees with human-visible content
- [ ] citations and evidence are used where appropriate
- [ ] no fabricated AI/provider claims
- [ ] no fake customer or performance claims

## Content quality

Every important public page:

- [ ] serves a real user/search intent
- [ ] provides original value
- [ ] is not thin
- [ ] is not duplicated from another page
- [ ] avoids keyword stuffing
- [ ] has useful internal links
- [ ] has appropriate supporting content
- [ ] has accurate facts
- [ ] has appropriate author/update information
- [ ] contains no placeholders
- [ ] contains no dead links
- [ ] contains no unsupported ranking guarantees

## Performance and accessibility

- [ ] mobile-first rendering verified
- [ ] Core Web Vitals checked
- [ ] important content renders reliably
- [ ] images optimized
- [ ] keyboard navigation works
- [ ] screen-reader-critical flows work
- [ ] contrast is acceptable
- [ ] reduced motion is respected
- [ ] charts have accessible alternatives
- [ ] important status does not rely on color alone

## External launch verification

- [ ] Google Search Console verified
- [ ] Bing Webmaster Tools verified
- [ ] sitemap submitted
- [ ] representative URLs inspected
- [ ] indexing diagnostics reviewed
- [ ] Bing AI Performance monitoring available where eligible
- [ ] IndexNow implemented and tested where appropriate
- [ ] analytics/consent configuration reviewed
- [ ] manual-action/security monitoring configured

## Blocking conditions

Do not launch publicly if any intended ranking page has:

- accidental noindex
- accidental crawler blocking
- wrong canonical
- missing critical content
- broken production redirect
- inaccessible important content
- contradictory entity information
- serious structured-data error
- placeholder content
- serious mobile failure
- serious performance regression
- critical accessibility failure
- missing legal requirements
- unresolved P0/P1 SEO/AEO/GEO issue

## Post-launch measurement

After launch, track rather than assume:

- indexed pages
- crawl errors
- impressions
- clicks
- CTR
- query coverage
- ranking distribution
- branded versus non-branded visibility
- AI citations
- AI mentions
- cited URLs
- referral traffic from AI/search
- conversion rate
- content performance
- technical regressions

The goal is not to declare victory on launch day. The goal is to launch with a clean foundation and then use actual search and AI data to improve continuously.
